# MedNarrate Desktop Build Guide

This document outlines how to build the native desktop packages for MedNarrate Admin using Tauri v2.

## Prerequisites

1. **Rust & Cargo**: Required to compile the Tauri backend.
   [Install Rust](https://www.rust-lang.org/tools/install)
2. **Node.js & npm**: Required to build the Next.js frontend and trigger Tauri CLI.

## Environment Variables

The packaged desktop app must point to the production backend API URL. Since it is statically exported, you **MUST** set the API URL at build time.

Set the following environment variable before running the build commands:
```bash
export NEXT_PUBLIC_API_BASE_URL="https://api.your-production-backend.com"
```

## Build Commands

Run these commands from inside the `mednarrate-admin-desktop` directory:

- **macOS Build (.dmg):**
  ```bash
  npm run build:desktop:mac
  ```

- **Windows Build (.msi / .exe):**
  ```bash
  npm run build:desktop:win
  ```
  *(Note: Building for Windows from a macOS machine requires a cross-compilation toolchain for `x86_64-pc-windows-msvc`, or you must run this command natively on Windows).*

## Pending Code Signing & Notarization

The current builds generated by these commands are **fully unsigned**. 

To distribute these packages in production without security warnings (like macOS Gatekeeper blocks or Windows SmartScreen), you need to provide your actual Developer Credentials to complete code-signing and notarization.

### Requirements for macOS
1. **Apple Developer Certificate** (Developer ID Application) installed in your Keychain.
2. **App-Specific Password** and **Apple ID** for notarization, OR an **App Store Connect API Key** (Issuer ID, Key ID, and the `.p8` key file).

### Requirements for Windows
1. **Windows Code Signing Certificate** (e.g., EV Cert or Standard Authenticode) in `.pfx` format.
2. The password for the `.pfx` file.

Once you have these credentials ready, we can configure `tauri.conf.json` and your environment variables to automatically sign the binaries during the build process.
