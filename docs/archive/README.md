# Archive

Point-in-time reports written while the admin portal and backend were being built and audited
(status matrices, gap analyses, repair manifests, debugging notes).

They are kept for history only. Some describe features that were later removed (Admin Copilot,
Governance, Privacy, Jobs) or bugs that are already fixed, so **do not treat them as current**.

The up-to-date record is:

- `AUDIT_REPORT.md` (repository root): every bug found and fixed, with its verification.
- `docs/admin/`: how the admin portal works today (setup, API, RBAC, security, deployment, testing).
- `docs/ML_MODELS_AND_XAI.md`: the models the app uses and how they are evaluated.
