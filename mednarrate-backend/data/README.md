# MedNarrate Data Storage

This folder holds local data for RAG and few-shot prompting.

- `knowledge_base/`: Drop medical textbook PDFs or internal clinical guidelines here. The `build_knowledge_base.py` script will parse these using PyMuPDF and ingest them into ChromaDB for RAG context during report analysis and chat.
- `examples/`: Place JSON or TXT files here containing ideal "few-shot" examples of clinical summaries. The `prompts.py` service will dynamically load these and insert them into the LLM context for consistent formatting.
- `kb_index/`: Autogenerated ChromaDB storage directory (git-ignored).
